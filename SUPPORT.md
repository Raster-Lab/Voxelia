# Support

## Supported platform scope

Community and release support is limited to Voxelia running on Apple Silicon hardware and the Apple operating-system versions declared by the active release. See `PLATFORM_SUPPORT.md`.

## Community support

Use GitHub Discussions for implementation questions and public issues for reproducible non-security defects and feature proposals.

## Security support

Use the private process in `SECURITY.md`.

## Release support

Supported versions, Apple operating-system minimums and Apple Silicon capability classes shall be stated in release notes. Pre-1.0 APIs and behaviours may change.

## Downstream responsibility

A host product remains responsible for application workflow, authentication, authorisation, patient privacy, deployment, clinical validation and regulatory approval.

Commercial support, integration and product-specific services are outside the open-source repository's community-support commitment.
