# VoxeliaImaging

**Purpose:** CT import, series assembly, value interpretation and multiplanar slicing.

**Direct dependencies:** VoxeliaExecution

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** Diagnostic-eligible import path: fail-closed admission over DICOM-derived CT data.
