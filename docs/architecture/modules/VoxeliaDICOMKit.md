# VoxeliaDICOMKit

**Purpose:** The DICOM boundary: frame sources, adapters and the optional capability protocols.

**Direct dependencies:** VoxeliaImaging, VoxeliaGeometry, DICOMKit (approved external)

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** Diagnostic-eligible import boundary; canonical modules cannot import DICOM by gate.
