# VoxeliaStorage

**Purpose:** Storage abstractions, contiguous sample storage, bricks and integrity claims.

**Direct dependencies:** VoxeliaCore

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** Diagnostic-eligible foundation: byte-exact contracts under the coordinated read boundary.
