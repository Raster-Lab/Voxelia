# VoxeliaCPU

**Purpose:** CPU reference implementations of the registered operations and surface extraction kernels.

**Direct dependencies:** VoxeliaImaging, VoxeliaGeometry, VoxeliaExecution

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** THE diagnostic reference: every registered CPU entry is exact or binary64-strict with recorded evidence.
