# VoxeliaCompression

**Purpose:** JPEG 2000 codec integration through approved external dependencies.

**Direct dependencies:** VoxeliaCore, J2KSwift (approved external)

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** Diagnostic-eligible decode path under the approved dependency identities.
