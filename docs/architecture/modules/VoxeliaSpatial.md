# VoxeliaSpatial

**Purpose:** Coordinate spaces, geometry, transforms, landmarks and the spatial algorithm vocabulary.

**Direct dependencies:** None (dependency-free foundation)

**Supported platforms:** Apple Silicon (`arm64`) on macOS 15+, iOS 18+, tvOS 18+ and visionOS 2+ — enforced by the manifest and the platform gate.

**Diagnostic status:** Diagnostic-eligible foundation: every model is frozen, oracle-pinned and admission-typed.
