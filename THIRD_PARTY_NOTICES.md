# Third-Party Notices

The M0 public runtime package intentionally declares no external package
dependencies.

When a dependency is introduced, add a reviewed entry containing:

| Field | Required value |
|---|---|
| Name | Dependency name |
| Repository | Canonical source repository |
| Version or revision | Resolved release or commit |
| Licence | SPDX-compatible licence identifier |
| Usage | Owning Voxelia target or tool |
| Distribution | Bundled, linked, build-only, test-only or optional |
| Notice requirements | Required attribution or notice text |
| Review | Reviewer and date |

GitHub workflow actions and development tools shall also be inventoried when
required by their licences or release process.
